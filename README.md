# azure-certification-sandbox

Bac à sable pour la préparation des certifications Microsoft Azure.

L'application est dans `web/`. L'accueil reprend la grille du poster Credentials (juillet 2026). Seul AZ-900 est jouable, en français et en anglais.

```bash
cd web
python3 -m http.server 8765
```

Ouvrez http://127.0.0.1:8765/
